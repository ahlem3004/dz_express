# DzExpress - User Stories

## 1. Client

### US-01: Inscription et connexion
En tant que client, je souhaite créer un compte et me connecter afin d'accéder à l'application.

Acceptance Criteria:
- The client can create an account.
- The client can log in with valid credentials.

### US-02: Consulter les produits
En tant que client, je souhaite consulter les produits disponibles afin de choisir les produits que je veux acheter.

### US-03: Passer une commande
En tant que client, je souhaite passer une commande afin d'acheter les produits sélectionnés.

Acceptance Criteria:
- The client can select available products.
- The client can confirm the order.

### US-04: Annuler une commande
En tant que client, je souhaite annuler ma commande afin de ne plus recevoir les produits commandés.

## 2. Commerçant

### US-05: Ajouter un produit
En tant que commerçant, je souhaite ajouter un produit afin de le proposer aux clients.

### US-06: Modifier un produit
En tant que commerçant, je souhaite modifier les informations d'un produit afin de maintenir le catalogue à jour.

### US-07: Consulter les commandes
En tant que commerçant, je souhaite consulter les commandes afin de préparer les produits demandés.

### US-08: Changer le statut de préparation
En tant que commerçant, je souhaite changer le statut de préparation d'une commande afin d'informer les autres acteurs.

## 3. Livreur

### US-09: Consulter les livraisons
En tant que livreur, je souhaite consulter les livraisons qui me sont attribuées afin de connaître les commandes à livrer.

### US-10: Modifier le statut de livraison
En tant que livreur, je souhaite modifier le statut d'une livraison afin d'informer le client de son avancement.

## 4. Administrateur

### US-11: Gérer les utilisateurs
En tant qu'administrateur, je souhaite gérer les utilisateurs afin de contrôler les accès à l'application.

### US-12: Gérer les comptes
En tant qu'administrateur, je souhaite gérer les comptes afin d'assurer leur bonne gestion.

### US-13: Superviser les commandes
En tant qu'administrateur, je souhaite superviser les commandes afin de suivre le fonctionnement du service.
