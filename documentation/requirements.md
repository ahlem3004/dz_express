# DzExpress - Requirements

## 1. Project Description
DzExpress is a home delivery application that connects customers, local merchants, delivery drivers, and administrators.

## 2. Actors and Functional Requirements

### Client
- Register and log in.
- Consult available products.
- Place an order.
- Cancel an order.

### Merchant
- Add a product.
- Modify a product.
- Consult orders.
- Change the preparation status of orders.

### Delivery Driver
- Consult assigned deliveries.
- Modify the delivery status.

### Administrator
- Manage users.
- Manage accounts.
- Supervise orders.

## 3. Project Objective
Organize the development work using Agile methods, Trello, Jira, and GitHub.
